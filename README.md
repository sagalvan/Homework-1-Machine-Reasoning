# Homework-1-Machine-Reasoning
 # A* Search for the 8-Puzzle

This project implements the **A* search algorithm** to solve the 8-puzzle problem. The assignment explores how different heuristic functions affect search performance, particularly the number of nodes generated and the effective branching factor.

## Project Overview

The 8-puzzle consists of eight numbered tiles and one blank space arranged on a 3 × 3 board. The goal is to move the tiles into the solved configuration:

```text
0 1 2
3 4 5
6 7 8
```

The project uses A* search to find a solution while tracking:

* Solution depth
* Number of nodes generated
* Average search cost for different solution depths

Random puzzle configurations are generated by shuffling the solved board through legal tile movements. This ensures that the generated puzzles are solvable.

## Heuristics

The project includes implementations of multiple heuristic functions, including:

* **Misplaced Tiles(H1):** Counts the number of tiles that are not in their goal positions.
* **Manhattan Distance(H2):** Adds the horizontal and vertical distances of each tile from its goal position.
* **Relaxed Adjacency(H3):** Counts the number of swaps with a number tile and the empty space.

### Changing Heuristics

The heuristic used by A* is selected in `Node.java`. **To test a different heuristic, you must manually update the heuristic calculation in both Node constructors, if applicable.**

For example, the constructors may currently use:

```java
this.h = board.calculateh3();
```

To test another heuristic, manually change this to the desired method, such as:

```java
this.h = board.calculateh1();
```

or:

```java
this.h = board.calculateh2();
```

The experiments will then use the updated heuristic when creating nodes.

## Main Classes

* **`Board.java`** — Represents the puzzle board, including tile movement, shuffling, goal-state checking, and heuristic calculations.
* **`Node.java`** — Represents a state in the search tree and stores the board, path cost `g`, heuristic value `h`, and total priority `f`.
* **`AStar.java`** — Implements A* search using a priority queue and an explored set.
* **`MapTrack.java`** — Groups search results by solution depth and calculates average nodes generated.
* **`Experiments.java`** — Generates random puzzle instances, runs A* search, and collects experimental results.

## Running the Project

1. Compile and run `Experiments.java`.
2. The program generates random solvable boards.
3. A* solves each board using the heuristic currently selected in `Node.java`.
4. The program records the solution depth and number of nodes generated.
5. Results are grouped by solution depth, and average search costs are calculated.

To compare heuristics, update the heuristic selection in `Node.java`, rerun the experiments, and compare the resulting search costs.
